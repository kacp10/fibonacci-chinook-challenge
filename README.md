## Mini‑app Fibonacci

### Requisitos
* Navegador moderno (Chrome/Firefox/Edge/Safari)
* Node ≥ 14 **o** Python ≥ 3.7 (solo para servir archivos estáticos)

### Arranque rápido

```bash
# opción 1: usando Node
cd Js        # carpeta que contiene index.html y fib.js
npx serve .  # instalará 'serve' en caliente si no existe

# opción 2: usando Python
cd Js
python -m http.server 8000
